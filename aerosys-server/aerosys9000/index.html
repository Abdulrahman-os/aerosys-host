Real-World Email Integration Note

The mail widget below simulates message composition and delivery in-browser. To make it send and receive real email, wire it to a transactional email API (e.g. SendGrid, Postmark, or AWS SES) from a small server function: POST the form payload to /api/mail/send, which calls the provider using a server-side API key (never expose that key client-side). Inbound replies can be routed to a shared inbox via the same provider's inbound-parse webhook.
